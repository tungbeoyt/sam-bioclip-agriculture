# Public evaluation evidence

`v3/` contains metrics and per-image predictions for 111 evaluation results. `v31/` adds 3 evaluations of existing no-smoothing LoRA checkpoints on PlantDoc. `training_metadata/` contains config, suite, history and source calibration for 87 distinct selected checkpoints. The 120-run count includes other historical candidates not selected for these evaluations. `analysis_final.json` and `supplement_analysis.json` contain the recomputed audit. Images and model checkpoints are not hosted in this Git repository.

The original PlantVillage source test is historical, not blind. Source and PlantDoc image paths in these artifacts are dataset identifiers from the local experiment and are not downloadable paths. Obtain images from the original dataset owners and follow their licenses.
